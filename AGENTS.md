# WasteWise project instructions

- Keep the project static, responsive, and free of required build tooling unless the owner explicitly changes the architecture.
- Do not add paid APIs or client-side secret keys.
- The current item sorter is keyword/rule based; never describe it as generative AI or image recognition.
- Disposal advice must say local rules vary. Be especially cautious with batteries, chemicals, medicines, e-waste and unknown materials.
- Never fabricate environmental impact figures, user testing, partnerships, or municipal approval.
- Maintain semantic HTML, keyboard-visible focus, reduced-motion support and live announcements.
- Run `node --check app.js` and the GitHub Actions validation workflow after JavaScript changes.
- Escape any user-provided values inserted into HTML.
- Do not add analytics or third-party trackers without explicit consent and disclosure.
