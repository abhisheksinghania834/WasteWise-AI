# Manual QA checklist

Complete each check before final submission; mark boxes only after testing the actual deployed site.

- [ ] Open on desktop and a narrow mobile viewport.
- [ ] Test “banana peel”, “plastic bottle”, “old battery”, “cardboard box”, and an unknown item in Quick Sort.
- [ ] Confirm sorting advice warns that local rules can differ.
- [ ] Search “glass” in Materials and use each filter.
- [ ] Log an action, refresh, and confirm same-browser persistence.
- [ ] Reset the action counter and test its confirmation dialog.
- [ ] Complete all quiz questions and verify feedback/next actions.
- [ ] Navigate using keyboard only and inspect focus indicators.
- [ ] Test behaviour with local storage blocked.
- [ ] Open the public app in a private window without signing in.
- [ ] Confirm GitHub Actions validation and deployment succeed.
- [ ] Record demo only after the deployed version is confirmed.
